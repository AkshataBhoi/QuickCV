# QuickCV - AI-Powered Resume Builder 🚀

QuickCV is a premium SaaS platform designed to help job seekers, especially software engineers, create ATS-optimized resumes and cover letters using the power of AI.

## ✨ Key Features

- **AI Resume Builder**: Create professional resumes with real-time AI suggestions for summaries and skills.
- **AI Cover Letter Generator**: Generate tailored cover letters for specific job roles and companies in seconds.
- **ATS Analysis**: Scan your resume against job descriptions to get an ATS score and actionable improvement tips.
- **Premium Templates**: Access modern, developer-focused templates that stand out to recruiters.
- **Secure Payments**: Premium plan unlocking with a seamless checkout experience.

## 💳 Premium Payment Setup

The project features a dedicated **Premium Payment Flow** designed for a trustworthy and high-converting experience:

1.  **Dashboard CTA**: A prominent "Upgrade to Premium" card in the dashboard nudges users to unlock advanced features like AI analysis and unlimited downloads.
2.  **Payment Page (`/payment`)**: A high-integrity, 2-column layout:
    -   **Left**: Clear plan summary highlighting the "Premium" benefits (30 AI Analysis scans, 10 Cover Letter credits, etc.).
    -   **Right**: A secure-looking payment form with real-time validation and localized currency support (₹).
3.  **Success State**: Immediate feedback upon successful payment, redirecting users back to their upgraded dashboard.

-   **Notifications**: [Sonner](https://sonner.stevenly.me/)
-   **Animations**: [Framer Motion](https://www.framer.com/motion/)

QuickCV aims to bridge the gap between candidate experience and recruiter expectations. By focusing on ATS optimization and developer-centric design, we provide tools that actually help users land interviews in a competitive tech market.
